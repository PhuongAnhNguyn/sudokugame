## 🎮 Sudoku Game

A web-based Sudoku game built with **HTML, CSS, and JavaScript**, featuring a clean interface, customizable game settings, and an interactive Sudoku board.

### ✨ Features

- **Interactive Sudoku Board:** Fill in the 9×9 grid using the on-screen number pad or keyboard.
- **Multiple Difficulty Levels:** Choose between Easy, Medium, and Hard.
- **Customizable Timer:** Set your own time limit in minutes for each game.
- **Progress Tracking:** Monitor your completion progress with a dynamic progress bar.
- **Game Assistance:** Use hints, erase entries, and check your answers.
- **Game Controls:** Start a new game or restart the current puzzle.
- **Light & Dark Mode:** Switch between two themes.
- **Music Player:** Load music playlists using YouTube or Spotify links.
- **Responsive Design:** Enjoy the game across different screen sizes.

### 🛠️ Technologies Used

- **HTML5** - Structure and layout.
- **CSS3** - Styling, responsive design, and theme customization.
- **JavaScript** - Sudoku generation, game logic, timer, progress tracking, and interactive features.
